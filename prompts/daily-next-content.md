# Daily next content: Faceless YouTube Content Channel (niche to be chosen)

## Inputs
Use the repo's `README.md` (the plan, money model, 30-day plan and success/kill criteria), the most recent files in `logs/` (newest first) and anything in `from-cto-new/`. If you're pasting this prompt into a chat assistant, paste or attach those files below it. If no logs are supplied, treat today as Day 1 of the 30-day plan.

## Task
Decide and draft the **next piece of channel work** for today.
1. From the README and logs, work out the stage: niche selection, channel setup, scripting or publishing, and any audience signals.
2. **If no niche is chosen yet:** propose 5 candidate niches. For each give the target viewer, 5 example video ideas, evidence of demand (describe the kind of channels and searches to check rather than inventing numbers), why we can be more useful than existing channels, likely RPM range (marked as an estimate), production effort, and AI-policy risk. Score each 1–5 and recommend one. **[KEVIN picks.]**
3. **If the niche is chosen:** plan the next video:
   - 3 title options and a thumbnail concept
   - the viewer's problem and the specific, useful answer the video gives
   - an outline with timestamps, then the full voiceover script (8–12 minutes)
   - a visual plan per section: screen recordings, diagrams, own footage or licensed stock (no copyrighted clips)
   - facts to verify, with the kind of source to check each one against
   - a 30–45 second Short script cut from the video
   - description, tags and whether YouTube's AI/synthetic-content disclosure applies
4. Originality check: in 3 bullets, say what makes this video original and useful rather than mass-produced, and how it differs from the last 3 videos.
5. Flag anything that needs Kevin with **[KEVIN]**.

## Output
Reply with a single markdown section that starts with the heading `## Next content`. It gets appended to `logs/YYYY-MM-DD.md` (today's date), either by the daily workflow or by Kevin pasting it in.

Rules:
- Don't make up numbers. If a metric isn't in the logs, write "unknown" and say who needs to supply it.
